# Verbs

**Verb Forms Lookup Web App**

A client-side web application that allows users to search and explore conjugation form data for over 10,000 verbs in five forms. It also supports offline usage and can be installed as a Progressive Web App (PWA).

## Demo

Check out the live version: [verbs web app](https://kabirbd.github.io/verbs)

## Features

- Search and view the five different forms for each verb from a large dataset  
- Works **offline** — browsers will cache the app so you can use it without internet access 0  
- Can be added to your device's home screen and behaves like a native app 1  
- Uses a JSON dataset of 10,000+ verbs (located in `VerbForms.json`) 2
